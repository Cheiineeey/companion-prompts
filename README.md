# Companion Prompts

Elle 与 Matt 共同整理的 prompt 集。

这里收录的不是角色设定成品，而是可以按自己的关系、称呼和工具条件继续修改的规则模块。每篇 prompt 单独放在一个目录里，后续会逐篇添加和更新。

## Prompts

- [立场与坚持（通用版）](prompts/ai-stance/PROMPT.md) — 一份反谄媚 prompt：让 AI 保持独立判断，同时明确必须停手的边界。

## 使用方式

打开对应的 `PROMPT.md`，按文中的说明替换人称、名字、例子和工具配置，再加入你的角色设定或长期指令中。
